### Tools required   
Duster

### Checklist
- [ ] Check placement of the machine. Ensure the sample mover has enough clearance for homing moves. 
- [ ] Check placement of lights and diffusers. Prevent collisions with the sample during homing.
- [ ] Check drag chain mounts.
- [ ] Check seating of all white motor cables.
- [ ] Check the vertical shift axis of the camera. The gantry should be set to the bottom of its range.
- [ ] Check the sensor rotation axis. The sensor carriage must be level.
- [ ] Check cable clearance behind the camera module.
- [ ] Check camera bellows.
- [ ] Dust off the sensor, RGB filter wheel, and lens.
- [ ] Remove lens cap on streaming cameras.
- [ ] Switch on main power.
- [ ] Switch on the secondary camera computer.
- [ ] Check if the frame grabber has loaded its configuration. If not, restart the camera computer.
- [ ] Start LinuxCNC on the motion computer.
- [ ] Home all axes. Stay alert for possible axis overruns or collisions with drag chains.
- [ ] Remove lens cap on the camera lens.
- [ ] Start the camera software.
- [ ] Load the camera configuration file.
- [ ] Run a test capture to verify all systems are functioning.

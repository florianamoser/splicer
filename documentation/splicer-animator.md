!!! tip "Prerequisite to run splicer-animator"  

    The script has so far only been tested on MacOS.  
    On Mac OS, Blender needs to be started from the command line. When starting Blender from the application launcher, the splicer-animation-script is not able to write the GCODE to the harddisk. Follow the link below for more informations on how to start blender from the command line.  
    [Blender Documentation MacOS: Launching from the command line](https://docs.blender.org/manual/en/latest/advanced/command_line/launch/macos.html)
